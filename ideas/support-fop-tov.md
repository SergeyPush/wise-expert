# Супровід — «що перестає бути вашою турботою»

Главный продающий блок страниц `/fop` и `/tov`. Перенесён из макета Claude Design «WisExpert Супровід ФОП ТОВ» — тексты и раскладка утверждены заказчиком в макете.

## Суть

Одна секция, две раскладки под тип аудитории — проп `data.layout`:

- **ФОП (`grid`)** — центрированный хед (чип + заголовок с акцентом + лид), под ним ровный ряд из четырёх карточек: налоги, отчётность, ответы на вопросы, меньше рисков. Формат «зоны ответственности, которые переходят к нам».
- **ТОВ (`split`)** — текст слева (липкий на десктопе: чип, заголовок, лид, выноска-обещание «беспокоим только когда нужно ваше решение»), справа сетка 2×2: податки та звітність, ПДВ, зарплата та кадри, первинні документи.

Под обеими раскладками — полоса с CTA: одно предложение + кнопка.

Карточки появляются со сдвигом снизу с задержкой 90 мс друг за другом (`useInView`), карточка приподнимается на hover.

## Акценты

Секция вводит второй акцентный цвет: **синий = ФОП, фиолетовый = ТОВ**. Внутри сетки цвета иконок чередуются (2+2), чтобы ряд из четырёх карточек не читался монотонной полосой. Токены `color-violet / color-violet-dark / color-light-violet` добавлены в `tailwind.config.js`, кнопка получила формат `primary-violet`.

## Отступление от правил ideas/README

README запрещает icon-grid из четырёх плиток. Здесь исключение: раскладка пришла из утверждённого макета, и карточки описывают конкретные зоны ответственности (ПДВ, первичка, кадры), а не общие слова. Секция стоит **первой** на странице, до тихой [«Чому WisExpert»](why-us-spec-list.md) — две смысловые сетки подряд ставить нельзя, порядок на странице обновлён ниже.

## Файлы

- `components/Support/Support.tsx` — обе раскладки, иконки инлайном (в react-icons нет аналогов для ПДВ и первички)
- `constants/support.const.ts` — `FOP_SUPPORT`, `TOV_SUPPORT`
- `interfaces/support.interface.ts`

```tsx
<Support data={FOP_SUPPORT} />   // /fop
<Support data={TOV_SUPPORT} />   // /tov
```

## Что подтвердить у заказчика

- Тексты взяты из макета дословно — правок не вносили.
- Короткие мобильные варианты чипа («Більше не треба розбиратися») и текста в полосе CTA — из мобильных фреймов макета.
- CTA открывает модалку `setBookCallIsVisible` — как у остальных секций. Если нужен скролл к калькулятору, поменять обработчик.
